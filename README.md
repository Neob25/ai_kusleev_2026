# Лабораторная работа №1. Разработка модели глубокого обучения для классификации изображений

## Цель работы
Целью данной лабораторной работы является разработка модели глубокого обучения с использованием библиотеки Keras для решения задачи классификации изображений, а также реализация средств визуализации полученных результатов.

## Выбор и подготовка датасета
Для выполнения поставленной задачи был выбран публичный датасет Intel Image Classification, загруженный с платформы Kaggle. Данный набор данных содержит около семнадцати тысяч изображений размером сто пятьдесят на сто пятьдесят пикселей, которые разделены на шесть классов природных и городских сцен, таких как здания, лес, ледник, гора, море и улица. Исходный архив содержит папки для обучения, тестирования и предсказания, однако для корректной работы кода папка с тестовой выборкой была переименована в валидационную, а папка для предсказаний была удалена как избыточная. Итоговая структура директорий включает в себя четырнадцать тысяч тридцать четыре изображения для обучения и три тысячи изображений для валидации.

## Предобработка данных и архитектура модели
Загрузка данных осуществлялась непосредственно с локального диска с помощью встроенной функции image_dataset_from_directory, которая автоматически определяет классы по названиям папок и формирует батчи по тридцать два изображения. Все изображения были приведены к разрешению девяносто шесть на девяносто шесть пикселей для оптимизации скорости обучения на центральном процессоре, после чего значения пикселей были нормализованы в диапазон от нуля до единицы с помощью слоя Rescaling. Для ускорения подачи данных в модель были применены методы кэширования и предзагрузки.

Разработанная нейронная сеть представляет собой последовательную сверточную архитектуру, состоящую из трех блоков. Каждый блок включает в себя сверточный слой с функцией активации ReLU и слой максимального пулинга. Количество фильтров последовательно увеличивается с тридцати двух до шестидесяти четырех и затем до ста двадцати восьми, что позволяет сети выделять от простых границ до сложных текстур. После сверточной части располагается слой Flatten для преобразования многомерных карт признаков в одномерный вектор, полносвязный слой на сто двадцать восемь нейронов, слой Dropout с коэффициентом ноль целых пять десятых для предотвращения переобучения и выходной слой с функцией активации Softmax для распределения вероятностей по шести классам. Общее количество обучаемых параметров модели составляет около одного миллиона семисот тридцати тысяч.

## Процесс обучения и визуализация
Компиляция модели была выполнена с использованием оптимизатора Adam и функции потерь sparse categorical crossentropy. В процессе обучения использовался написанный автором колбэк LivePlotCallback, который в режиме реального времени перерисовывал графики точности и потерь после каждой эпохи. Кроме того, применялся механизм ранней остановки EarlyStopping, который отслеживал значение функции потерь на валидационной выборке с параметром терпения равным трем эпохам и возвращал веса модели с наилучшими показателями.

Анализ графиков обучения показал, что наиболее высокие результаты были достигнуты на пятой эпохе, где точность на валидации составила восемьдесят два целых восемь десятых процента, а значение потерь снизилось до нуля целых пятидесяти двух сотых. Начиная с шестой эпохи значение потерь на валидации начало возрастать, что свидетельствовало о начале переобучения. Благодаря механизму EarlyStopping обучение было прервано после восьмой эпохи, а веса модели были автоматически возвращены к состоянию пятой эпохи, что позволило сохранить высокую обобщающую способность сети.

## Анализ результатов классификации
Для визуализации результатов работы модели была реализована функция, выводящая сетку из девяти изображений с истинными и предсказанными метками. Зеленый цвет заголовка свидетельствует о верном предсказании, а красный указывает на ошибку. Анализ полученных изображений показал, что модель успешно распознает большинство объектов, однако допускает характерные ошибки из-за ориентации на доминирующие цвета и текстуры. Например, изображения зданий на фоне обширного синего неба или стеклянных фасадов были ошибочно классифицированы как море, а внутренний двор с брусчаткой и фонарями был определен как улица. Это объясняется тем, что базовая сверточная сеть без дополнительных механизмов аугментации в первую очередь опирается на цветовые пятна, а не на семантические границы объектов.

## Вывод
В ходе выполнения лабораторной работы была успешно разработана и обучена сверточная нейронная сеть для классификации изображений на шесть классов. Достигнутая точность на валидационной выборке составила восемьдесят два целых восемь десятых процента. Использование механизма ранней остановки позволило предотвратить переобучение и автоматически выбрать наилучшие веса модели. Разработанные средства визуализации наглядно демонстрируют процесс обучения и позволяют анализировать ошибки модели на конкретных примерах.
