# Лабораторная работа №3. Разработка модели генерации текстов

## Цель работы
Целью третьей лабораторной работы является разработка модели глубокого обучения для генерации текстов на основе ранее выбранного датасета.

## Выбор подхода и подготовка данных
В качестве исходного набора данных был взят датасет Intel Image Classification, использовавшийся в первых двух лабораторных работах. Поскольку данный датасет состоит исключительно из изображений и не содержит текстового корпуса, было принято решение реализовать мультимодальную задачу Image Captioning, которая заключается в генерации текстовых описаний для входных изображений. Для каждого класса изображений были сформированы текстовые шаблоны, имеющие структуру вида «startseq на изображении название_класса endseq». На основе этих шаблонов с помощью слоя TextVectorization был построен словарь и проведена токенизация текста.

## Архитектура модели
Разработанная нейронная сеть состоит из двух параллельных ветвей, которые объединяются на этапе принятия решения. Ветвь обработки изображений базируется на предобученной сверточной нейросети MobileNetV2, веса которой были заморожены для ускорения обучения и предотвращения переобучения. Данная ветвь извлекает из картинки размером девяносто шесть на девяносто шесть пикселей пространственные признаки и сжимает их в плотный вектор с помощью слоя глобального усреднения. Ветвь обработки текста принимает последовательность слов, преобразует их в плотные векторы с помощью слоя Embedding и обрабатывает рекуррентным слоем LSTM для запоминания контекста. Полученные векторы изображения и текста объединяются с помощью слоя конкатенации, после чего проходят через полносвязный слой и слой Softmax для предсказания следующего слова в последовательности.

## Процесс обучения и генерации
Для обучения модели применялся специально написанный генератор данных, который в бесконечном цикле формировал обучающие пары. На вход нейросети поочередно подавался префикс предложения и соответствующее изображение, а целевой меткой выступало следующее слово. Такой подход позволяет сети учиться предсказывать текст пошагово. При непосредственной генерации текста на вход модели подается стартовый токен и изображение, после чего предсказанное слово добавляется к входной строке, и процесс повторяется до появления маркера конца предложения. Для управления степенью разнообразия генерируемых фраз был реализован механизм температурного сэмплирования, который изменяет вероятностное распределение предсказываемых слов.

## Анализ результатов
В ходе первоначального эксперимента, когда сверточная сеть обучалась с нуля, модель не успевала выделить устойчивые визуальные признаки за короткое время, что приводило к генерации случайных текстов. Применение переноса обучения с использованием MobileNetV2 позволило модели опираться на уже готовые, качественные признаки изображений. В результате итоговая модель успешно научилась сопоставлять визуальные паттерны с текстовыми описаниями. Визуализация результатов демонстрирует, что сгенерированные фразы в большинстве случаев корректно определяют класс объекта на изображении, а использование температурного сэмплирования позволяет гибко регулировать связность и предсказуемость итогового текста.

## Вывод
В ходе выполнения третьей лабораторной работы была успешно разработана модель генерации текстов на основе ранее выбранного визуального датасета. Совместное использование предобученной сверточной нейросети и рекуррентной сети LSTM позволило реализовать задачу генерации текстовых описаний для изображений. Модель продемонстрировала способность извлекать смысловые признаки из картинок и на их основе формировать связные текстовые последовательности.
